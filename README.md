# 🏥 Disease Prediction System

## Overview

A Machine Learning project that predicts the likelihood of diseases such as Diabetes, Heart Disease, and Breast Cancer using patient medical data. The system uses multiple classification algorithms and provides a simple Streamlit-based web interface for real-time predictions.

## Features
* Data Collection from Medical Datasets
* Data Cleaning & Preprocessing
* Feature Scaling & Encoding
* Multiple ML Models Comparison
* Logistic Regression, Random Forest, SVM, XGBoost
* Model Evaluation (Accuracy, Precision, Recall)
* Streamlit Web Application
* Real-time Disease Prediction System

## Dataset Features

## Diabetes Dataset
* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age

## Heart Disease Dataset
* High BP
* High Cholesterol
* BMI
* Smoking Status
* Stroke History
* Physical Activity
* General Health
* Age
* Education
* Income

## Breast Cancer Dataset
* Radius Mean
* Texture Mean
* Perimeter Mean
* Area Mean
* Smoothness Mean
* Compactness Mean
* Concavity Mean
* Symmetry Mean
* Fractal Dimension Mean

## Results
* Breast Cancer (SVM Accuracy): 98.25%
* Diabetes (Logistic Regression Accuracy): 75.32%
* Heart Disease (Logistic Regression Accuracy): 90.85%
